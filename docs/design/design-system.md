# Ratatoskr Check: Design System

**Status:** Initial draft

## 1. Purpose

This document defines the visual guidelines and design principles of Ratatoskr Check.

Its purpose is to maintain a consistent, accessible, and recognizable user interface across the application.

## 2. Visual Identity

Ratatoskr Check follows a **professional and warm** visual direction.

The interface should communicate reliability, clarity, and organization without adopting an overly corporate appearance.

The visual identity is based on the following principles:

- Professional and approachable.
- Clean and easy to navigate.
- Consistent typography, spacing, and component styles.
- Limited and functional color palette.
- Visual elements that support information rather than distract from it.

## 3. Color Direction

The initial color direction is **Forest & Cream**.

The palette will explore natural, warm, and neutral tones, with forest green as the primary identity color.

The application will support two visual themes:

- Light theme: initial default theme.
- Dark theme: alternative theme.

Both themes should preserve the same visual identity and maintain sufficient contrast and readability.

**Note:** Exact color values are pending definition.

## 4. Typography

The application should use a consistent typography system.

Typography guidelines:

- One primary font family.
- Defined sizes for headings, subtitles, body text, and secondary information.
- Consistent font weights and line spacing.
- Readability takes priority over decorative styling.

**Note:** Font family and typography scale are pending definition.

## 5. Layout and Components

The interface should use consistent layout rules and reusable visual components.

Initial component guidelines:

- Consistent spacing and alignment.
- Standardized buttons and form controls.
- Reusable cards and tables.
- Clear visual hierarchy.
- Consistent borders, backgrounds, and corner radii.

## 6. Usability and Accessibility

The interface should prioritize clarity and ease of use.

- Information must be easy to identify and understand.
- Color should not be the only indicator of status.
- Text and interactive elements must maintain sufficient contrast.
- Visual consistency should be preserved across application screens.

## 7. Mascot and Visual Elements

Ratatoskr, the squirrel mascot, is part of the application's visual identity.

The mascot should provide personality and warmth without interfering with the application's primary purpose as an audit management tool.

Decorative elements should remain secondary to functional content.
